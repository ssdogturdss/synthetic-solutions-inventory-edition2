# React Native with Expo

Start the development server with `npx expo start`.

## Native builds in Clownin

This starter includes Expo and EAS build profiles. Before a native build, an admin must link this app to an EAS project in the shared Expo account and set that project's ID at `expo.extra.eas.projectId` in `app.json`. The ID must belong to the connected account. Customize the example iOS bundle identifier and Android package before store release. Then open the project and choose **Deploy → Native builds**.
